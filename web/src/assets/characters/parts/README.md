# 분리 이미지로 무무 움직이기

## 내보내기 규칙
- 모든 부위를 **820 × 900px 투명 PNG**, 같은 캔버스와 같은 위치로 저장합니다.
- 부위만 잘라서 캔버스를 줄이거나 가운데로 옮기지 마세요. 투명 여백을 그대로 유지합니다.
- 레이어들을 같은 위치에 겹치면 완성된 캐릭터가 보여야 합니다.
- body.png에는 팔·다리·꼬리를 중복해서 그리지 않습니다. 얼굴 레이어도 분리했다면 몸에는 눈·입을 그리지 않습니다.
- 팔 끝은 어깨에 살짝 겹치게 그리면 회전할 때 틈이 보이지 않습니다.

## 파일명과 저장 위치
해당 단계 폴더(stage-1 ~ stage-6)에 넣습니다. 예: stage-1/body.png

| 파일 | 내용 | 필수 여부 |
| --- | --- | --- |
| body.png | 몸통·머리 | 필수. 이 파일이 있어야 분리 모드가 켜짐 |
| left-arm.png | 화면 왼쪽 팔 | 선택 |
| right-arm.png | 화면 오른쪽 팔, 인사하는 팔 | 선택 |
| left-leg.png / right-leg.png | 화면 기준 왼쪽·오른쪽 다리 | 선택 |
| tail.png | 꼬리, 몸 뒤에 표시 | 선택 |
| shadow.png | 바닥 그림자 | 선택 |
| cap.png | 머리 위 껍질 모자 등 | 선택 |
| face.png | 얼굴 전체 | 선택 |
| eyes.png / mouth.png | 눈과 입 | 선택, 있으면 눈 깜빡임 지원 |

분리 파일이 없는 단계는 현재 완성 PNG가 그대로 표시됩니다. body.png가 없는 상태에서 팔만 넣으면 분리 모드로 전환되지 않습니다.

## 표정 파일 (선택)
face/eyes/mouth 뒤에 -happy, -tired, -frustrated, -anxious, -bored, -calm, -default를 붙일 수 있습니다.
예: eyes-happy.png, mouth-happy.png. 해당 감정 파일이 없으면 eyes.png / mouth.png를 사용합니다.

## 관절 위치 (필요한 경우에만)
기본 어깨·발·꼬리 위치로 바로 재생됩니다. 그림 비율이 크게 달라 관절이 어긋나면 같은 폴더의 joints.json에서 조절할 수 있습니다.
아래 좌표는 코드 안의 205 × 225 기준입니다. 820 × 900 원본의 좌표를 4로 나누면 됩니다.

```json
{
  "rightArm": [142, 157],
  "leftArm": [63, 157],
  "leftLeg": [81, 190],
  "rightLeg": [125, 190],
  "tail": [144, 180],
  "eyes": [101, 128],
  "shadow": [102, 211]
}
```

## 확인
http://localhost:5173/?characterPreview=1 에서 단계와 모션을 고릅니다.
안녕: 오른팔 회전 / 폴짝: 몸·양팔·다리 / 하트: 양팔 모으기 / 기본 대기: 숨쉬기·꼬리 흔들기·눈 깜빡임.
나중에 이미지만 첨부하고 단계와 부위 이름을 알려주면 이 폴더에 넣어 연결할 수 있습니다.
