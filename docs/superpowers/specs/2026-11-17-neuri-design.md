# 느리 — 설계 (2026-11-17 승인)

## 목적
기분이 처진 사람이 달팽이 "느리"와 대화하면 지금 기운에 맞는 활동 하나를 추천받고, 서버가 인증한 활동만 경험치가 되어 캐릭터가 자라는 모바일 웹. 2026-11-20~21 해커톤 시연용, 목요일(11-19) 클라우드 배포.

## 목표 / 하지 않는 것
- 목표: 대화 → 추천 → 인증 → 성장 → 쿠폰, 위기 키워드 → 안전 모드가 실제 서버·DB·LLM으로 끝까지 동작.
- 하지 않는 것: 로그인(테스트 사용자 1명 고정), 실제 지도 API, 사진 저장, PostGIS.
- 금지: 경험치·레벨 감소, 인증 후 원래 좌표 저장, API 키의 프론트 노출, LLM/DB 실패 시 화면 멈춤.

## 접근
1. **채택: 단일 배포 단위.** `server/`(Express + TS + `pg`)가 `web/`(React + Vite) 빌드 결과를 정적 서빙. Dockerfile 1개, 로컬 DB는 docker compose.
2. 프론트·백 분리 배포: CORS와 배포 두 번이 필요해 5일 일정에 불리.
3. ORM(Prisma 등) 사용: 테이블 11개에 SQL 파일 하나면 충분해 제외.

## 결정 사항 (사용자 지정)
- 테이블, API, 인증 규칙, 화면, seed, 구현 6단계는 원 명세 그대로.
- LLM: OpenAI 호환 구현체가 기본. `LLM_BASE_URL / LLM_MODEL / LLM_API_KEY`만 바꿔 Gemini·Groq 등으로 교체.
- 예비 공급자 `LLM_FALLBACK_*`. 429·타임아웃(8초)·오류 → 예비 → 기본 답장.
- JSON 출력 모드에 의존하지 않고 응답 텍스트에서 JSON을 추출한 뒤 zod 검증. 검증 실패 시 1회 재시도.
- LLM 호출 횟수를 서버 로그에 남김(일자별 누적).
- `PlaceRepository` 인터페이스 유지. 지금은 PostgreSQL `places` 테이블(seed 6곳) 구현체.
- `.env`는 커밋하지 않고 `.env.example`만.
- README: 실행 방법 + 휴대폰 테스트용 HTTPS 터널링.
- 확인 스크립트: 두 시나리오를 API로 한 번에 실행.

## 내가 정한 것 (바꿀 수 있음)
- LLM 호출은 SDK 없이 `fetch`. Anthropic 전용 구현체는 만들지 않음 — Anthropic도 OpenAI 호환 엔드포인트가 있어 같은 구현체로 됨. 필요해지면 `LLMClient` 구현체 하나 추가.
- 거리 계산은 하버사인. 지도 미리보기는 SVG 약도.
- 숫자 설정값(반경, 경험치, 일일 상한, 만료 시간)은 `server/src/config.ts` 한 곳.
- 사진은 메모리에서 이미지 여부만 확인하고 버림.
- 영업시간은 `open_hours` jsonb `{open:"09:00", close:"21:00"}`, 서버 시간(Asia/Seoul) 기준. DEMO_MODE에서는 항상 영업 중.
