# 느리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 달팽이 "느리"와 대화 → 기운별 활동 추천 → 서버 인증 → 성장 → 쿠폰, 그리고 위기 감지 → 안전 모드가 실제로 도는 해커톤 시연용 모바일 웹.

**Architecture:** `server/`(Express + TypeScript + `pg`)가 API와 `web/`(React + Vite) 빌드 결과를 함께 서빙하는 단일 배포 단위. LLM은 `LLMClient` 인터페이스 뒤의 OpenAI 호환 구현체(주 → 예비 → 기본 답장), 장소는 `PlaceRepository` 인터페이스 뒤의 PostgreSQL 구현체.

**Tech Stack:** Node 24, Express 5, TypeScript, tsx, pg, zod, node:test / React 18, Vite / PostgreSQL 16 (docker compose) / Docker.

**Spec:** `docs/superpowers/specs/2026-11-17-neuri-design.md` (+ 대화에 붙여 넣은 원 명세)

## Global Constraints

- 경험치·레벨이 줄어드는 코드 경로를 만들지 않는다.
- API 키는 서버 env에만. 프론트 번들·응답에 포함 금지.
- 위치는 인증할 때만 사용. `activity_runs.start_lat/lng`는 인증 완료·만료 시 NULL로 지운다. 사진은 저장하지 않는다.
- LLM·DB 실패 시 5xx로 화면을 멈추지 않고 기본 응답을 돌려준다.
- LLM 타임아웃 8초. 429·타임아웃·오류 → 예비 공급자 → 기본 답장.
- LLM 출력은 텍스트에서 JSON 추출 → zod 검증 → 실패 시 1회 재시도.
- 숫자 설정값은 전부 `server/src/config.ts`: `SEARCH_RADIUS_M=1500, NEAR_MOVE_M=100, TOWN_RADIUS_M=100, EXP={HOME:5,NEAR:15,TOWN:30}, DAILY_EXP_CAP=100, RUN_TTL_MIN=60, STAGE_MIN_EXP=[0,30,80,150], COUPON_STAGE=3, LLM_TIMEOUT_MS=8000`.
- 문구: 첫 대화 화면 "느리는 AI 캐릭터예요", 홈·제휴 매장 "체험 모드: 매장과 쿠폰은 가상입니다", 안전 모드 109 / 1577-0199 (`tel:` 링크).
- `.env`는 커밋 금지, `.env.example`만.
- 사용자는 id=1 테스트 사용자 고정(로그인 없음).

## Review Focus

1. LLM이 JSON 앞뒤에 설명이나 ```코드펜스```를 붙임 → 추출해서 정상 처리 (Task 2 테스트).
2. LLM이 후보에 없는 id를 고르거나 picks가 비어 있음 → 없는 id는 버리고, 2개 미만이면 서버가 후보 앞에서 채움 (Task 3 테스트).
3. 같은 run을 두 번 인증 → 두 번째는 경험치 0, 중복 지급 없음 (Task 4 테스트).
4. 일일 상한 도달 → `verified:true, expGained:0`으로 정상 완료, 오류 아님 (Task 4 테스트).
5. 위치 권한 거부(lat/lng 없음) → DEMO_MODE면 DEMO_CENTER 사용, 아니면 TOWN 후보 없이 HOME/NEAR만 추천 (Task 3 테스트).
