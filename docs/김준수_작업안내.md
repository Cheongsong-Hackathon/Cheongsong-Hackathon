# 김준수 작업 안내 (화면·캐릭터·시연)

무드패스는 지금 **처음부터 끝까지 동작하는 상태**입니다. 이제 휴대폰에서 보기 좋게 다듬고 시연을 준비하는 단계입니다. 서버·AI는 김승제, 화면은 김준수가 맡습니다.

- 저장소: https://github.com/Cheongsong-Hackathon/Cheongsong-Hackathon
- 배포 주소: https://blackapple.store (휴대폰으로 바로 열 수 있음)
- 대회: 2026-11-20(금)~21(토). 발표 5분, 그중 시연 3분 이내. 제출물에 데모 영상 포함

## 1. 처음 한 번 준비

필요한 것: Node 22 이상, Docker Desktop, Git

```powershell
git clone https://github.com/Cheongsong-Hackathon/Cheongsong-Hackathon.git
cd Cheongsong-Hackathon
copy .env.example .env               # LLM 키는 비워 둬도 됨 (기본 답장으로 동작)
docker compose up -d db              # PostgreSQL (localhost:5433)
cd server; npm install; cd ..
cd web; npm install; cd ..
```

## 2. 매일 실행

터미널 두 개를 엽니다.

```powershell
# 터미널 1: 서버 (API + DB 연결)
cd server; npm run dev

# 터미널 2: 화면 (저장하면 바로 반영)
cd web; npm run dev
```

브라우저에서 **http://localhost:5173** 을 엽니다. 화면만 고치더라도 서버는 켜 둬야 데이터가 나옵니다.

- 서버 포트는 `.env`의 `PORT`(기본 3000)입니다. 다른 프로그램이 3000번을 쓰고 있으면 `PORT=3100`처럼 바꾸면 화면 쪽도 알아서 따라갑니다.
- 서버 코드가 바뀐 뒤(`git pull` 후)에는 서버 터미널에서 `Ctrl+C` 후 `npm run dev`를 다시 실행하세요. 자동으로 다시 안 뜰 때가 있습니다.
- 데이터를 처음 상태로 돌리려면 `cd server; npm run seed` (내 컴퓨터 DB만 지워짐)

## 3. 화면 흐름

```
휴대폰 메인 화면 → 무드패스 아이콘 → 랜딩 → 위치 동의 → 앱
앱: 01 마음 확인(홈) → 02 조건(시간·거리·예산) → 03 추천 → 04 예약 요청 → 05 다녀왔어 + 기분 기록 → 토끼 성장
탭: 홈 · 체험 · 기록 · 속마음
```

## 4. 내가 고치는 파일 (`web/src/`)

| 파일 | 들어 있는 것 |
| --- | --- |
| `screens.tsx` | 거의 모든 화면: 홈, 조건 시트, 추천 카드, 예약 확인, 예약 요청 완료, 기분 기록, 축하, 미루기, 기록, 체험 목록, 랜딩, 위치 동의, 안전 모드 |
| `App.tsx` | 화면 순서, 하단 탭, 휴대폰 테두리 크기, API 호출과 로딩·오류 처리 |
| `styles.css` | 색, 글자 크기, 여백 (색은 맨 위 `:root` 변수) |
| `Bunny.tsx` | 토끼 SVG: 표정, 성장 단계, 꾸미기 아이템(리본·목도리·베레모) |
| `Art.tsx` | 체험 카드의 분류별 그림 |
| `Launcher.tsx` | 첫 화면인 휴대폰 메인 화면과 앱 아이콘 |
| `Chat.tsx` | 속마음 대화 탭 |
| `api.ts` | 서버 호출 함수. 함수는 그냥 가져다 쓰면 되고, **함수 자체를 고치거나 추가할 때는 김승제에게 먼저 말하기** (서버와 맞물려 있음). 어떤 API가 있는지는 `README.md`의 API 표 |

`server/` 폴더는 김승제 담당이라 고치지 않습니다. 서버에 필요한 게 있으면 말로 요청하세요.

## 5. 할 일 (위에서부터)

1. **휴대폰 실기 테스트**
   - https://blackapple.store 를 내 휴대폰으로 열고 전체 흐름을 끝까지 눌러 보기
   - 깨지는 화면, 너무 작은 글자, 손가락으로 누르기 어려운 버튼을 고치기
   - 아이폰·안드로이드를 하나씩은 확인
2. **기다리는 화면·빈 화면**
   - AI 답이 늦을 때(최대 8초) 멈춘 것처럼 보이지 않게 로딩 표시
   - 연결이 끊겼을 때 안내, 기록이 하나도 없을 때 화면
   - 확인 방법: 서버를 끄고 눌러 보기 / 크롬 개발자도구 Network에서 "Slow 3G"
3. **캐릭터 다듬기** (디자인 팀원과)
   - 토끼 표정, 성장 단계별 모습, 꾸미기 아이템
4. **새 기능 화면 붙이기** (서버와 `api.ts` 함수는 준비됨, 화면만 없음)

   | 기능 | 부를 함수 | 화면에서 할 것 |
   | --- | --- | --- |
   | 주소 설정 | `api.geocode('영남대학교')` → `{lat, lng, label}` | 위치 동의 화면(그리고 추천 조건 시트)에 "주소로 설정" 입력칸. 받은 좌표를 `localStorage`에 저장하고, 저장된 게 있으면 `getPos()` 대신 그 좌표를 `recommend`·`experiences`·`freePlaces`에 넘김. "📍 영남대학교 경산캠퍼스 ▸ 바꾸기"처럼 지금 기준 위치를 보여 주기 |
   | 무료 장소 | 추천 응답의 `free` / `api.freePlaces(pos)` | **추천 화면에는 김승제가 붙여 둠** (`Recs`의 "돈 안 드는 곳", 카카오맵 길 안내 링크). 모양 다듬기, 체험 탭에도 넣을지는 김준수 판단 |
   | 도착 확인 | `api.arrive(booking.id, await getPos())` → `{arrived}` | 진행 중 예약 카드에 "도착했어" 버튼. `arrived: true`면 "방문 확인 ✓" (`booking.arrivedAt`로도 알 수 있음). `false`여도 "다녀왔어"는 막지 않기 (재촉·불이익 없음이 원칙) |

   - 주소 검색은 서버에 카카오 키가 있어야 동작합니다. 로컬에서 쓰려면 김승제에게 키를 받아 `.env`의 `KAKAO_REST_API_KEY`에 넣으세요.
   - 체험 모드(`DEMO_MODE=true`)에서는 도착 확인이 거리와 상관없이 통과합니다. 청송 대회장에서 시연할 수 있게 한 것입니다.

5. **시연 준비**
   - 3분짜리 시연 순서 정하기 (예: 메인 화면 → 마음 확인 → 추천 → 예약 요청 → 다녀왔어 → 토끼 성장)
   - 데모 영상 녹화 (제출물)

## 6. 지켜야 할 문구 (심사에서 볼 수 있음)

- 토끼는 **AI 캐릭터**라고 화면에 표시
- "체험 모드: 매장·가격·결제는 가상" 표시 유지
- 예약은 **"예약 요청"**. "예약 완료", "결제 완료"라고 쓰지 않기
- 위기 표현이 나오면 나오는 안전 화면(109, 1577-0199)은 빼지 않기
- `/api/talk` 응답에 `support`가 있으면 추천 카드 아래에 작게 보여 주기: `support.text` 한 줄 + `support.lines`의 번호를 `tel:` 링크로. 추천을 가리거나 막지 않기 (위기를 AI가 놓쳤을 때의 안전망)
- "우울"이라는 단어는 쓰지 않기 (팀에서 뺐음)

## 7. 작업 순서 (Git)

```powershell
git checkout main; git pull
git checkout -b feature/작업이름        # 예: feature/mobile-fix
# ... 작업 ...
cd web; npm run build                   # 이게 통과해야 함
git add web/src; git commit -m "fix: 무엇을 고쳤는지"
git push -u origin feature/작업이름
```

- 끝나면 GitHub에서 `main`으로 Pull Request를 만들거나, 김승제에게 합쳐 달라고 말하기
- 작게, 자주 합치기 (하루에 여러 번). 오래 들고 있을수록 충돌이 커짐
- `.env`는 절대 커밋하지 않기 (키가 들어 있음)

## 8. 알아 두면 좋은 것

- **사용자는 브라우저마다 따로**입니다. 시크릿 창을 열면 새 사용자(새 토끼)로 시작합니다. 시연 전에 깨끗한 상태가 필요하면 시크릿 창을 쓰면 됩니다.
- **AI 키가 없으면** 공감 한마디와 추천 이유가 미리 써 둔 기본 문장으로 나옵니다. 화면 작업에는 문제없습니다.
- **위치**: http에서는 위치 권한을 묻지 않고, 시연 기준 위치(가상 매장 주변)로 추천합니다. https://blackapple.store 에서는 권한 창이 뜹니다.
- **배포 서버에 반영**은 김승제가 합니다 (`main`에 합친 뒤 서버에서 다시 빌드).
